# Enphase PowerPack cloud integration for Home Assistant

This repo includes a custom HA component at:

`homeassistant/custom_components/enphase_powerpack/`

It signs into Enlighten (same cloud path as the website) and exposes Battery SOC, PV power, load, battery power, and grid power — **no local Gateway port 443 required**.

See [homeassistant/custom_components/enphase_powerpack/README.md](homeassistant/custom_components/enphase_powerpack/README.md) for install steps.
